**14 ימי ניסיון חינם**, ואחרי זה הפעלה בתשלום.

**מה כלול:** מפת רשת חיה, טופולוגיית OSPF, ניטור SNMP של נתבים ומתגים, SNMP Traps, התראות בזמן אמת, דוחות SLA ורוחב פס, גילוי רשת, הרצת פקודות SSH, ייצוא CSV, התחברות LDAP/Active Directory ו-HTTPS.

רוצים גם ניטור WiMAX (BS ו-CPE, RSSI/CINR, מיקומי GPS)? ראו את [NetMonitor Full](https://github.com/Omri768/Netmon-Full).

## הורדה והתקנה

1. מורידים את הקובץ `NetMonitor-v7-Network-Setup.exe` מ-[Releases](../../releases/latest).
2. מריצים כמנהל מערכת (Windows 10/11 או Windows Server 2016 ומעלה, 64-bit).
3. אחרי ההתקנה המערכת נפתחת בכתובת `https://localhost:8443`. שם המשתמש הוא `admin`, והסיסמה הראשונית נמצאת בקובץ `C:\ProgramData\NetMonitor7\FIRST-RUN-ADMIN-PASSWORD.txt`.
